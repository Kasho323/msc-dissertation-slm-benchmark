使用步骤 / How to use

1. 点左上角 📂 载入 CSV,选择打分文件(第一段选 human_stage1_independent_60_2026-06-29.csv)。
2. 每屏一个答案:读题 → 读预期答案要点 → 读模型答案 → 给六个维度各打 0-5 分 → 写一句备注(低分必写)→ 下一个。
3. 键盘快捷键:直接按数字 0-5 给当前高亮的维度打分并自动跳到下一维度;←/→ 上一个/下一个答案;N 聚焦备注框。
4. 进度自动保存在浏览器里(localStorage),中途关掉浏览器也不会丢,重新载入同一个 CSV 即可继续。
5. 全部打完后点右上 ⬇ 导出,把下载的文件发给 Claude 做后续统计。

打分原则:0=不可用 1=很差 2=弱 3=可接受 4=好 5=优秀。以 3 为重心,4 要"确实好",5 要"挑不出毛病"。幻觉维度分越高=编造越少。

## 第 3 步:打分(核心环节)

**每个答案的节奏(约 60-90 秒):**

1. **读题**(加粗那行)
2. **读"预期答案要点"**——这是你出题时写的标准,答案该说什么都在这里
3. **读"模型答案"**(蓝底框)
4. **打六个分**:一行一个维度,黄色高亮行是当前维度
   - **最快方式:直接按键盘数字 0-5**,打完自动跳下一维度
   - 也可以用鼠标点数字按钮
5. 六个都打完,平均分自动算出,这个答案自动标 ✓
6. **备注**:按 `N` 跳到备注框,写一句(**低分必写**,比如 "编造了 XX" / "漏了要点后半"),写完按 `Esc` 退出备注框
7. 按 **回车** 或 **→** 进入下一个答案

**六个维度问自己什么:**

| 维度 | 问自己 |
|---|---|
| 相关性 | 它在回答这道题吗? |
| 正确性 | 对照预期要点,说的对吗? |
| 忠实度 | 说法能在证据里找到吗? |
| 完整性 | 要点覆盖了多少? |
| 幻觉(高=好) | 有编造吗?5=完全没有 |
| 来源依据 | 明显基于材料,还是泛泛而谈? |

**分数标尺(贴在心里):**
- 0 = 没答/不可用 · 1 = 很差 · 2 = 弱 · **3 = 可接受(重心)** · 4 = 确实好 · 5 = 挑不出毛病
- ⚠️ 常见错误:手软全打 4。**敢打 2,吝啬 5**,不然模型之间拉不开差距,结果没意义

**键盘速查:**
| 键 | 作用 |
|---|---|
| 0-5 | 给当前高亮维度打分 |
| ↑ ↓ | 上下切换维度 |
| ← → 或回车 | 上/下一个答案 |
| N | 跳到备注框(Esc 退出) |

## 常见问题

**Q: 打错分了怎么改?**
A: 用 ↑↓ 移到那个维度,重新按数字;或者鼠标直接点正确的分数按钮。任何时候都能改。

**Q: 某个答案被截断了(话说一半没了)怎么打?**
A: 照实打——截断自然会伤"完整性",该低就低。备注写 `truncated`。这正是我们要测量的东西。

**Q: 两个答案感觉一样好,我分不出来?**
A: 那就打一样的分,不需要强行区分。

**Q: 我想跳过某个答案回头再打?**
A: 直接按 → 跳过,顶部下拉框里没打完的显示 "·",打完的显示 "✓",随时用下拉框跳回去。

**Q: 不小心把浏览器数据清了/进度丢了?**
A: 导出按钮随时可用,养成习惯:**每做完一批就导出一次**当备份(会提示"还有 X 个未打完",确认导出即可)。

**Q: 打分打到怀疑人生,标准越来越松/紧?**
A: 正常。停下来,回看自己最早打的 5 个,对齐标准再继续。这就是为什么要分几次打。

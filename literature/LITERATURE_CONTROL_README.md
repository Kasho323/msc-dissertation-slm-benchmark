# Literature Control

Use the literature files in this order:

1. `MASTER_REFERENCE_PLAN.md` controls the reference-count target, candidate sources, verification state, and source quality.
2. `reference_theses/SHARED_THESIS_STYLE_ANALYSIS.md` controls what can be learned from the five example theses.
3. `literature_matrix.md` records reading progress and the one-line purpose of sources that are retained.
4. `research_gap.md` and `search_keywords.md` support searching and gap refinement.

Where an older note in `literature_matrix.md` mentions a target of around 30 papers, it is superseded by the current whole-dissertation target in `MASTER_REFERENCE_PLAN.md`: approximately 55-70 unique, relevant references, with 45 as a practical minimum.

No source should be cited merely to reach this target. Final technical claims should prefer original papers and official documentation; privacy and governance claims should prefer authoritative institutions and original security research.
